# Hotkeys

Scout's shortcuts are global: they work in any app and need no permission. Apart from the start shortcut, they are registered only while you record, so they never take a key combination away from other apps otherwise. Scout takes no bare letter keys while recording, so typing in the app you are recording is never affected.

## While not recording

| Keys | Action |
|---|---|
| `⌃⌥S` | Start scouting (a walkthrough) |

You can change the start shortcut in the *Point* step of the setup guide (menu bar panel → *Setup guide*).

## While recording

| Keys | Action |
|---|---|
| `⌃⌥S` | Finish |
| `⌥` (hold) | Aim: outline the element under the pointer |
| `⌥`-click | Pin the element under the pointer |
| `⌥`-drag | Draw on the screen |
| `⌃⌥B` | Start a new ask (walkthrough) or a new task (tasks) |
| `⌃⌥E` | Keep both recent areas in view; press again to widen to the window, then the screen, then back to following |
| `⌃⌥⇧E` | Follow the pointer again |
| `⌃⌥X` | Discard the recording: press once to ask, again to confirm |
| `Esc` | Keep the recording (while the discard question shows) |

## Task cards

| Keys | Action |
|---|---|
| `⌘↩` | Send the focused card (when auto-send is off) |
| `⌥⌘↩` | Send all cards (when auto-send is off) |

## Review window

| Keys | Action |
|---|---|
| `Space` | Play or pause |
| `↑` / `↓` | Previous or next task |
| `⌘B` | Split the selected task at the playhead |
| `⌘J` | Join the selected task with the next one |
| `⌘⌫` | Delete the selected task |
| `⌘Z` | Undo |
| `⌘↩` | Send the selected task |
| `⌥⌘↩` | Send all tasks |

## Walkthrough destination sheet

| Keys | Action |
|---|---|
| `↑` `↓` | Move through the list |
| `Tab` | Jump to the next group (`⇧Tab` goes back) |
| `Enter` | Paste into the chosen chat |
| `⌘↩` | Send to the chosen chat or session |
| `Esc` | Leave the walkthrough on the clipboard only |
